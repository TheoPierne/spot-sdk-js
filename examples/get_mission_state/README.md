# Retrieving Mission state

This example program demonstrates how to retrieve information about the state of the currently-running mission.

## Setup Dependencies

The example uses the SDK of this repository: install its dependencies at the root of the repository with:

```
npm install
```

## Running the Example

To run the example:

```
node get_mission_state.js ROBOT_IP
```
