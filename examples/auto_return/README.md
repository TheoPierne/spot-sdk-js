# Auto Return Example

This example starts AutoReturn functionality manually with a force-acquired lease.

## Setup Dependencies

The example uses the SDK of this repository: install its dependencies at the root of the repository with:

```
npm install
```

## Run the Example

To run the example:

```
node force_start_auto_return.js ROBOT_IP
```
