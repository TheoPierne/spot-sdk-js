### tick

```ts
tick(sessionId: string, leases?: Lease[], inputs?: KeyValue[], leaseResources?: string[], groupName?: string, params?: DictParam, args?: Object): Promise<remotePb.TickResponse>
```

Tick the remote node.

| Parameter | Type | Description |
|---|---|---|
| `sessionId` | `string` | The session identifier |
| `leases` | `Lease[]` | Array of lease protobufs to use during the tick. (*Optional*) |
| `inputs` | `KeyValue[]` | any inputs needed by the remote node. (*Optional*) |
| `leaseResources` | `string[]` | List of resource names to use from the lease wallet. Only applied if no leases are provided. (*Optional*) |
| `groupName` | `string` | Callbacks can be used to record data using Data Acquisition. The mission can provide a hint to the callback with the current group, so that the data the callback saves is correctly grouped with other data generated by the mission. The value may change during ticking. (*Optional*) |
| `params` | `DictParam` | Parameters set by the client. Depending on the structure of the mission, the value may change during ticking. (*Optional*) |
| `args` | `Object` | Extra arguments for controlling RPC details. (*Optional*) |

**Returns** `Promise<remotePb.TickResponse>`
