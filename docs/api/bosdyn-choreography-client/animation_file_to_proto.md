# bosdyn-choreography-client/animation_file_to_proto

A tool to convert animation files into protobuf messages which can be uploaded to the robot and used within
choreography sequences.

```js
const { Animation, convertAnimationFileToProto, handleNestedDoubleValueParams, ... } = require('spot-sdk-js');
// Several modules export these names with different values: they are required from the module.
const { main } = require('spot-sdk-js/src/bosdyn-choreography-client/animation_file_to_proto');
```

## Animation

```ts
class Animation
```

Helper class to track values read from the animation file that are important to choreographer and necessary when
uploading animated moves.

### Properties

| Property | Type | Description |
|---|---|---|
| `name` | `string \| null` | The name of the animated move. |
| `bpm` | `number \| null` | [Optional] The BPM which the move will be performed at. |
| `frequency` | `number \| null` | [Optional] The frequency at which the keyframes occur. If not provided in the CHA file, then explicit timestamps must be provided for each keyframe. |
| `description` | `string` | Default description for the animated move. |
| `proto` | `choreographySequencePb.Animation` | The protobuf message representing the animation. |
| `rgb` | `number[]` | The color of the animated move's block when loaded in Choreographer. |
| `parameterLines` | `string[]` | Each individual parameter line as read from a *.cha file. |

### createMoveInfoProto

```ts
createMoveInfoProto(): choreographySequencePb.MoveInfo
```

Creates the MoveInfo protobuf message from the parsed animation file.

**Returns** `choreographySequencePb.MoveInfo`: The MoveInfo protobuf message for the animation as generated by the different animation fields in the Animation proto.

## convertAnimationFileToProto

```ts
export function convertAnimationFileToProto(animatedFile: string, animateMoveParamsFile?: string): Animation
```

Parses a file into the animation proto that will be uploaded to the robot.

| Parameter | Type | Description |
|---|---|---|
| `animatedFile` | `string` | The filepath to the animation text file. |
| `animateMoveParamsFile` | `string` | [Required if needing default param values. Otherwise optional] The filepath to a default set of move parameters or move parameters as a string. (*Optional*) |

**Returns** `Animation`: The Animation class, which contains the animation proto to be uploaded to the robot, as well as additional information to be used by Choreographer.

**Throws**

- `AnimationFileFormatError` The file is not a valid animation file.

## handleNestedDoubleValueParams

```ts
export function handleNestedDoubleValueParams(proto: any, name: string, attributeValue: any): void
```

Helper function to set a field to a DoubleValue protobuf in a protobuf message.

| Parameter | Type | Description |
|---|---|---|
| `proto` | `any` | Any generic protobuf message. |
| `name` | `string` | The field name within the protobuf message. This name should be both the field name and sub-field name separated by a period. For example, for the Vec3 velocity field, the name would be 'velocity.x'. |
| `attributeValue` | `any` | A value with type matching the field type defined in the protobuf message definition. This will be saved in the name field. |

**Throws**

- `TypeError` There is no such DoubleValue field.
