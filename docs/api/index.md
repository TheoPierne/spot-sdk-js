# spot-sdk-js

The entry point of the package, require('spot-sdk-js'): the public API of the SDK. The clients of the Spot CAM,
of the GPS and of Orbit, and the modules of generic names (text and JSON formats of the messages, images, protobuf
descriptors) are in the namespaces spotCam, gps, orbit, textFormat, jsonFormat, imageUtil and descriptorPool. A few
names are exported by several modules with different values (e.g. the NoTimeSyncError of graph_nav, robot_command
and audio_visual): they are required from their module, e.g. require('spot-sdk-js/src/bosdyn-client/graph_nav').

```js
const { Animation, AnimationFileFormatError, COMMENT_DELIMITERS, ... } = require('spot-sdk-js');
```
