# bosdyn-client/data_acquisition_helpers

Helpers for the data acquisition service: acquisition requests, their cancellation, and the download of the
acquired data from the REST API of the robot.

```js
const { issueAcquireDataRequest, acquireAndProcessRequest, cancelAcquisitionRequest, ... } = require('spot-sdk-js');
```

| Export | Kind | Description |
|---|---|---|
| [`issueAcquireDataRequest`](#issueacquiredatarequest) | Function | Sends the data acquisition request without blocking until the acquisition completes. |
| [`acquireAndProcessRequest`](#acquireandprocessrequest) | Function | Send acquisition request and optionally block until the acquisition completes. |
| [`cancelAcquisitionRequest`](#cancelacquisitionrequest) | Function | Cancels an acquisition request based on the request id |
| [`cleanFilename`](#cleanfilename) | Function | Removes bad characters in a filename. |
| [`makeTimeQueryParams`](#maketimequeryparams) | Function | Create time-based query params for the download request. |
| [`makeTimeQueryParamsFromGroupName`](#maketimequeryparamsfromgroupname) | Function | Create time-based query params for the download request using the group name. |
| [`downloadDataREST`](#downloaddatarest) | Function | Retrieve all data for a query from the DataBuffer REST API and write it to files. |

## issueAcquireDataRequest

```ts
export function issueAcquireDataRequest(dataAcqClient: DataAcquisitionClient, acquisitionRequests: any, groupName: string, actionName: string, metadata?: dataAcquisitionPb.Metadata, dataTimestamp?: any): Promise<{
    requestId: number;
    actionId: dataAcquisitionPb.CaptureActionId;
}>
```

Sends the data acquisition request without blocking until the acquisition completes.

| Parameter | Type | Description |
|---|---|---|
| `dataAcqClient` | `DataAcquisitionClient` | DataAcquisition client for send the acquisition requests. |
| `acquisitionRequests` | `any` | Acquisition requests to include in request message. |
| `groupName` | `string` | Group name for the acquisitions. |
| `actionName` | `string` | Action name for the acquisitions. |
| `metadata` | `dataAcquisitionPb.Metadata` | Metadata to include in the request message. (*Optional*) |
| `dataTimestamp` | `any` | Timestamp to use for the acquisitions. If None the timestamp will be generated by the data acquisition client. (*Optional*) |

**Returns** `Promise<{ requestId: number; actionId: dataAcquisitionPb.CaptureActionId; }>`: A request id set as null indicates the AcquireData rpc failed.

**Throws**

- `RpcError` Problem communicating with the robot.

## acquireAndProcessRequest

```ts
export function acquireAndProcessRequest(dataAcquisitionClient: DataAcquisitionClient, acquisitionRequests: dataAcquisitionPb.AcquisitionRequestList, groupName: string, actionName: string, metadata?: dataAcquisitionPb.Metadata, blockUntilComplete?: boolean, dataTimestamp?: any): Promise<boolean>
```

Send acquisition request and optionally block until the acquisition completes.
If blocking, the GetStatus RPC is used to monitor the status of the acquisition request.

| Parameter | Type | Description |
|---|---|---|
| `dataAcquisitionClient` | `DataAcquisitionClient` | The client for send the acquisition requests. |
| `acquisitionRequests` | `dataAcquisitionPb.AcquisitionRequestList` | Acquisition requests to include in request message. |
| `groupName` | `string` | Group name for the acquisitions. |
| `actionName` | `string` | Action name for the acquisitions. |
| `metadata` | `dataAcquisitionPb.Metadata` | Metadata to include in the request message. (*Optional*) |
| `blockUntilComplete` | `boolean` | If true, don't return until the GetStatus completes. (*Optional*) |
| `dataTimestamp` | `any` | Timestamp to use for the acquisitions. If None the timestamp will be generated by the data acquisition client. (*Optional*) |

**Returns** `Promise<boolean>`: Whether the acquisition completed successfully.

**Throws**

- `RpcError` Problem communicating with the robot.

## downloadDataREST

```ts
export function downloadDataREST(queryParams: dataAcquisitionStorePb.DataQueryParams, hostname: string, token: string, destinationFolder?: string, additionalParams?: {
    [x: string]: any;
} | null): Promise<boolean>
```

Retrieve all data for a query from the DataBuffer REST API and write it to files.
Like Python, the certificate of the robot is not checked.

| Parameter | Type | Description |
|---|---|---|
| `queryParams` | `dataAcquisitionStorePb.DataQueryParams` | Query parameters to use to retrieve metadata from the DataStore service. Must be time-based query parameters only. |
| `hostname` | `string` | Hostname to specify in URL where the DataBuffer service is running. |
| `token` | `string` | User token to specify in https GET request for authentication. |
| `destinationFolder` | `string` | Folder where to download the data. (*Optional*) |
| `additionalParams` | `{ [x: string]: any; } \| null` | Additional GET parameters to append to the URL. (*Optional*) |

**Returns** `Promise<boolean>`: Boolean indicating if the data was downloaded successfully or not.
